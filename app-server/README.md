# KServer Client App

这是一个Android客户端应用，用于通过Shizuku权限管理和测试KServer截图服务。

## 功能特性

### 🔐 Shizuku集成
- 自动检测Shizuku安装和运行状态
- 请求和管理Shizuku权限
- 通过Shizuku执行Shell命令

### 🚀 KServer管理
- 使用Shizuku权限启动KServer Socket模式
- 自动部署和管理KServer DEX文件
- 实时监控KServer运行状态

### 📱 截图功能
- **PNG截图**: 标准PNG格式截图
- **JPEG截图**: 压缩JPEG格式截图
- **RAW截图**: 原始RGBA数据截图
- **实时预览**: 在应用内显示截图结果

### 📊 性能测试
- **基准测试**: 运行完整的性能基准测试
- **内存测试**: 检测内存泄漏和使用情况
- **实时统计**: 显示处理时间和数据大小

### 🔗 网络通信
- 使用OkHttp进行Socket通信
- 支持二进制数据传输
- 自动重连和错误处理

## 使用步骤

### 1. 准备工作
1. 确保设备已安装Shizuku应用
2. 启动Shizuku服务（通过ADB或Root）
3. 确保KServer DEX文件在 `/data/local/tmp/k-server.dex`

### 2. 应用操作
1. **启动应用**: 打开KServer Client
2. **授权Shizuku**: 点击"请求Shizuku权限"按钮
3. **启动KServer**: 点击"启动KServer"按钮
4. **等待连接**: 应用会自动连接到KServer
5. **开始截图**: 使用各种截图按钮进行测试

### 3. 状态指示
- **Shizuku状态**: 显示权限授予状态
- **KServer状态**: 显示服务运行状态  
- **连接状态**: 显示Socket连接状态

## 故障排除

### 常见问题

1. **Shizuku权限被拒绝**
   - 确保Shizuku应用已启动
   - 检查ADB或Root权限

2. **KServer启动失败**
   - 检查DEX文件是否存在
   - 确认设备权限充足

3. **连接失败**
   - 检查端口8888是否被占用
   - 确认KServer服务正在运行

4. **截图失败**
   - 检查屏幕录制权限
   - 确认设备支持截图功能
